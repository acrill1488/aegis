# AEGIS Specification

## 1. Что такое AEGIS

AEGIS - это локальная AI Operating System, представляющая собой локального AI co-worker, работающего на серверном ПК. Рабочий ПК выступает в роли клиента и рабочей среды. Система предоставляет надежную, безотказную модель, которая может выполнять сложные задачи в изолированной локальной среде.

## 2. Главная архитектура

AEGIS построена на следующих основных компонентах:

- **Core**: Центральный хаб системы AEGIS, управляющий общим состоянием системы, координирующий работу между различными модулями и предоставляющий базовые сервисы.
- **Brain**: Компонент, отвечающий за принятие решений и обработку запросов пользователя.
- **Runtime**: Отвечает за выполнение AI-агентов и управление их жизненным циклом.
- **Prompt Compiler**: Компонент для формирования промптов с учетом контекста.
- **Output Parser**: Обрабатывает выходные данные и извлекает финальный ответ.
- **Knowledge Engine**: Источник знаний, предоставляющий доступ к различным источникам информации.
- **Memory**: Система хранения памяти для различных типов данных.
- **Workspace**: Изолированная среда для работы агентов.
- **Session**: Управление пользовательскими сессиями и контекстом взаимодействий.
- **Task**: Компонент для планирования и выполнения задач.
- **Planner**: Алгоритмы планирования задач.
- **Executor**: Компонент для выполнения запланированных задач.
- **Tool Registry**: Реестр инструментов доступных в системе.
- **Browser**: Браузерная платформа для работы с веб-контентом.
- **OCR**: Система оптического распознавания символов.
- **Vision**: Компьютерное зрение и обработка изображений.
- **Voice**: Голосовая платформа для обработки речи.
- **Image**: Платформа для работы с изображениями.
- **n8n**: Платформа автоматизации процессов.
- **Game Companion**: Система для взаимодействия с игровыми приложениями.
- **Plugin SDK**: SDK для создания плагинов.

## 3. Жизненный цикл запроса

User Request → Session → Brain → Router → Knowledge Engine → Prompt Compiler → Runtime → Output Parser → Memory → Response

## 4. Prompt Compiler

Компонент Prompt Compiler формирует промпты с использованием следующих блоков:

- **Identity block**: Определение личности агента
- **Project Context**: Контекст проекта
- **Memory Context**: Контекст памяти
- **Workspace Context**: Контекст рабочей среды
- **Web Context**: Веб-контекст
- **Tool Context**: Контекст инструментов
- **Task Context**: Контекст задачи
- **Output Rules**: Правила форматирования вывода
- **Examples**: Примеры использования

## 5. Output Parser

Output Parser выполняет следующие функции:

- Удаление reasoning
- Удаление think-тегов
- Удаление tool JSON
- Извлечение финального ответа

## 6. Knowledge Engine

Knowledge Engine предоставляет доступ к следующим источникам знаний:

- **Browser**: Веб-браузер для поиска информации
- **Web Search**: Поиск в интернете
- **GitHub**: Доступ к репозиториям GitHub
- **Hugging Face**: Доступ к моделям Hugging Face
- **Wikipedia**: Информация из Википедии
- **Local Memory**: Локальная память
- **Workspace files**: Файлы рабочей среды
- **Ranking**: Ранжирование результатов поиска
- **Summarization**: Суммаризация информации

## 7. Memory Architecture

Система памяти включает следующие компоненты:

- **Working Memory**: Краткосрочная память
- **Long-term Memory**: Долгосрочная память
- **Project Memory**: Память проектов
- **User Preferences**: Предпочтения пользователя
- **Reflection Memory**: Память рефлексий
- **Knowledge Base**: База знаний
- **Vector Memory**: Векторная память (в будущем)

## 8. Task Lifecycle

Жизненный цикл задачи включает следующие этапы:

- **create**: Создание задачи
- **plan**: Планирование задачи
- **execute**: Выполнение задачи
- **reflect**: Рефлексия и анализ результата
- **remember**: Запоминание результата

## 9. Tool System

Система инструментов включает:

- **ToolResult**: Результат выполнения инструмента
- **ToolRegistry**: Реестр инструментов
- **Dispatcher**: Диспетчер инструментов
- **safe execution**: Безопасное выполнение команд
- **filesystem**: Работа с файловой системой
- **powershell**: Выполнение PowerShell команд
- **git**: Работа с системой контроля версий Git
- **browser**: Браузерные операции
- **future tools**: Будущие инструменты

## 10. Browser Platform

Браузерная платформа предоставляет следующие возможности:

- **fetch**: Получение данных из интернета
- **summarize**: Суммаризация контента
- **research**: Поиск информации
- **citations**: Цитирование источников
- **актуализация знаний модели через интернет**: Обновление знаний через интернет

## 11. OCR and Vision

OCR и Vision платформы включают:

- **Unlimited-OCR**: Бесконечное оптическое распознавание
- **Qwen3-VL**: Модель Qwen3-VL для визуального понимания
- **screen analysis**: Анализ экрана
- **UI understanding**: Понимание пользовательского интерфейса
- **documents**: Работа с документами
- **games**: Поддержка игровых приложений

## 12. Voice Platform

Голосовая платформа включает:

- **STT**: Распознавание речи (Speech-to-Text)
- **TTS**: Синтез речи (Text-to-Speech)
- **voice personality**: Голосовая личность
- **interruption**: Обработка прерываний
- **conversation memory**: Память разговоров

## 13. Image Platform

Платформа изображений включает:

- **ComfyUI**: Интерфейс для работы с изображениями
- **FLUX/SDXL**: Модели генерации изображений
- **image generation**: Генерация изображений
- **image editing**: Редактирование изображений
- **image tools**: Инструменты работы с изображениями

## 14. n8n Platform

Платформа n8n предоставляет возможности автоматизации:

- **automations**: Автоматизация процессов
- **Gmail**: Интеграция с Gmail
- **Telegram**: Интеграция с Telegram
- **Discord**: Интеграция с Discord
- **Calendar**: Интеграция с календарями
- **Drive**: Интеграция с Google Drive
- **GitHub**: Интеграция с GitHub

## 15. Game Companion

Система Game Companion включает:

- **online mode**: Режим онлайн - только собеседник, анализ экрана, голос, overlay
- **singleplayer mode**: Режим одиночной игры - можно включать управление
- **game memory**: Память игровых процессов
- **character/personality**: Персонажи/личности
- **NeuroSama-like behavior**: Поведение подобное NeuroSama

## 16. Plugin SDK

Plugin SDK предоставляет возможности для создания плагинов:

- **plugins**: Плагины
- **tools**: Инструменты
- **skills**: Навыки
- **configs**: Конфигурации
- **install/uninstall**: Установка и удаление плагинов

## 17. Package / Feature Installer

Система установки пакетов/функциональности:

- **aegis install browser**: Установка браузерной функциональности
- **aegis install vision**: Установка функциональности компьютерного зрения
- **aegis install voice**: Установка голосовой функциональности
- **aegis install image**: Установка функциональности работы с изображениями
- **aegis install n8n**: Установка функциональности n8n

## 18. Safety and Control

Система безопасности и контроля:

- **режимы safe / ask / auto**: Безопасный, спрашивающий, автоматический режимы
- **online game restrictions**: Ограничения в онлайн-играх
- **filesystem restrictions**: Ограничения файловой системы
- **command whitelist**: Белый список команд
- **user confirmation for dangerous actions**: Подтверждение опасных действий пользователем

## 19. Coding Standards

Стандарты кодирования:

- **module API**: Интерфейсы модулей
- **no circular imports**: Отсутствие циклических импортов
- **Typer CLI convention**: Соглашения Typer CLI
- **tests**: Тестирование
- **compileall**: Компиляция всех файлов
- **ruff**: Проверка стиля кода
- **pytest**: Тестовая система
