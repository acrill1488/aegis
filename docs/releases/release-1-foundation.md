\# Release 1. Foundation



\## Цель



Получить рабочего локального Codex-помощника.



\## Состав Release 1



\- Git-репозиторий AEGIS

\- VS Code на рабочем ПК

\- Node.js

\- Python

\- рабочая папка F:\\AI\_WORKSPACE

\- сервер AEGIS-SRV на Ubuntu Server 24.04 LTS

\- Docker на сервере

\- Ollama на сервере

\- Open WebUI

\- подключение VS Code агента к Ollama

\- первая модель для кода



\## Результат



ИИ-помощник умеет:



\- читать проект;

\- редактировать файлы;

\- писать код;

\- запускать команды;

\- видеть ошибки;

\- исправлять ошибки;

\- работать через локальную модель на сервере.
