# AEGIS Vision Screen Assistant

## Назначение модуля

Модуль AEGIS Vision Screen Assistant предоставляет безопасный функционал для захвата экрана с компьютера. Он позволяет создавать скриншоты основного монитора и сохранять их в указанную директорию.

## Режим безопасности

Данный модуль разработан с учетом безопасности и конфиденциальности:

- **Нет отправки данных в интернет** - все скриншоты остаются локально на компьютере
- **Нет управления мышью** - не производится автоматическое взаимодействие с элементами интерфейса
- **Нет управления клавиатурой** - не производится автоматическое ввод данных
- **Ограниченный доступ к системным ресурсам** - используется только минимально необходимый функционал для захвата экрана

## Функциональность

### Основная команда

```bash
aegis screen
```

Команда создает скриншот основного монитора и сохраняет его в директорию `F:\AI_WORKSPACE\screenshots` с уникальным именем, содержащим временную метку.

### Будущие команды

Планируется расширение функциональности модуля следующими командами:

#### aegis screen describe

Описание текущего состояния экрана в текстовом формате для последующего использования ИИ.

#### aegis screen ask

Задать вопрос о содержимом экрана с использованием ИИ для анализа.

#### aegis screen act

Выполнить автоматическое действие на основе анализа содержимого экрана.

## Технические детали

### Зависимости

- `mss` - для захвата скриншотов
- `pillow` - для работы с изображениями

### Путь сохранения

По умолчанию все скриншоты сохраняются в директорию:
```
F:\AI_WORKSPACE\screenshots
```

Имя файла формируется по шаблону:
```
screenshot_YYYYMMDD_HHMMSS.png
```

## Использование

```bash
# Создать скриншот
aegis screen

# Проверить систему
aegis doctor
```

## Безопасность

Модуль разработан с учетом следующих принципов безопасности:
1. Локальное хранение данных
2. Минимальный набор прав доступа
3. Отсутствие автоматического взаимодействия с системой
4. Предотвращение утечки информации
